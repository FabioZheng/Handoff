A plain-language read on Experiment 10

Notes That Age Badly

Ask an agent to summarise a document for the question you just asked, and it will write a note that answers that question well — and throws away almost everything else the document could have told you. Not because the note was too short. It had room for both.

1 The setup

Two agents. The first one reads a document you will never show the second one. It writes a short note. The second agent sees only that note and has to answer a question from it.

The only thing we change is what the note-writer knows. Sometimes we tell it the question that is coming. Sometimes we tell it nothing. Then we ask the reader a question the writer was never shown, and see what survived.

2 Making it a fair fight

The obvious objection is that a note written for a known question is simply shorter or longer than one written blind. So the note is put on a strict word budget, and every version has to land inside it.

That turned out to matter more than expected. Given only an upper limit, the question-aware writer used about a third less of its allowance than the blind writer — it had what it needed and stopped. Any difference in the results would then have meant nothing more than it wrote less. So the budget was given a floor as well as a ceiling.

3 What happened

Each note is scored twice: on the question its writer was told about, and on the questions its writer never saw.

Notice the last pair. A writer shown all four questions hits the same 82% on the question that matters — using the same 38 words — and gives up nothing on the other three.

So the note was never too small to carry the rest. The writer simply had no reason to keep it.

The third bar pair is the one worth pausing on. That writer was explicitly told that other, unknown questions might follow, and asked to keep evidence that would still be useful. It barely helped: it still ends up close to the question-aware writer, and still below the blind one on the questions nobody named.

4 Which settings are worth using at all

There are 24 ways to run this — six kinds of writer at four budgets. Most of them are simply beaten: some other setting does at least as well on the question you asked and at least as well on the ones you didn't, without spending more words. Only ten survive that test.

The shape of the survivors tells the practical story. If all you care about is the question in hand, the cheapest question-aware note wins — 20 words buys you the best score on that question of anything here. If you care about both, every option that is not badly lopsided is a writer that was shown the questions. There is no setting that specialises and keeps the rest.

5 The tighter the budget, the worse the trade

Widening the budget does not remove the effect, it just softens it. The writer's accuracy on its own question barely moves — it was already doing that job. What grows is what it manages to keep for everything else.

6 How far the damage reaches

A second set of documents was written specifically to answer this: how different does a later question have to be before the note stops helping? Each one is built so that every unseen question sits at a known distance from the one the writer was told about — the same fact reworded, a neighbouring fact about the same subject, something else in the same section, or a topic from a completely different part of the document.

The uncomfortable part is that the budget was not tight here. There was room to spread out, and the blind writer did spread out. The question-aware writer used the extra space to go deeper on the corner it had already chosen.

7 What to do with this

  • A handoff written for a task is not a reusable artifact

    If a summary was produced to answer something specific, treat it as spent. Caching it and querying it later gets you the shape of the original question back, not the document.

  • Telling the writer "more questions may come" is not enough

    It was tried directly. The note barely moves. Vague future-proofing does not compete with a concrete question sitting in the prompt.

  • If you know the question set, name it — it is nearly free

    A writer shown all the questions matched the specialist on the current one and kept the rest, at the same length. Where the downstream questions are enumerable, listing them costs almost nothing and saves almost everything.

  • Keep the source reachable

    The cheapest fix is not a better summary. It is making sure the second agent can still get back to the document when the question changes.

8 How far to trust it

This is one model writing and one model reading, across 24 encyclopedia passages with four questions each and 16 purpose-built documents with sixteen questions each — roughly 18,000 scored answers. Every question was checked first to confirm the reader could not already answer it from memory, so nothing here is the model recalling a fact it never received.

The effect is consistent across both document sets and holds under three separate checks that the notes really were the same length. What it has not yet been tested against is a second model family, a wider range of writing styles, or human graders instead of an automated one.
